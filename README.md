# ResilientKV

## Distributed Key-Value Store with Raft Consensus

ResilientKV is an academic distributed key-value store designed
as an M.Tech trimester project.

## Objectives

- Build a key-value storage engine
- Implement an LSM-tree storage architecture
- Implement Raft consensus
- Provide client communication using gRPC
- Deploy the system on Kubernetes
- Add monitoring using Prometheus and Grafana
- Perform fault-injection testing
- Evaluate system performance

## Technology Stack

- Go
- LSM-Tree
- Raft
- gRPC
- Kubernetes
- Helm
- Prometheus
- Grafana
